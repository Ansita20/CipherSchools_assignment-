# AI Usage

AI tools, primarily Claude, were used as a development assistant during this project. I used AI mainly for suggestions, design discussions, repetitive implementation work, and troubleshooting. I reviewed the suggestions and made the final decisions based on the project requirements.

## 1. UI and Page Design

**AI suggested:** Using standard layouts and component structures for the login page and main application page.

**Decision:** Accepted.

**Why:** These were mostly repetitive UI and layout tasks. Using AI suggestions helped speed up implementation while keeping the pages consistent with the rest of the application.

## 2. LLD Structure and Design Suggestions

**AI suggested:** Different ways to structure classes, responsibilities, and relationships for LLD problems such as Parking Lot and Elevator System.

**Decision:** Partially accepted.

**Why:** I used the suggestions to compare different design approaches, but did not blindly follow them. I selected responsibilities and abstractions based on the actual requirements and kept the design simple rather than adding unnecessary patterns.

## 3. Repetitive Implementation Work

**AI suggested:** Boilerplate code and implementation approaches for parts of the application that followed common patterns.

**Decision:** Accepted with review.

**Why:** This reduced repetitive coding effort and allowed me to focus more on the core functionality. I reviewed and modified the generated suggestions where they did not fit the project's existing structure.

## 4. AI API Integration and Slow Responses

**AI suggested:** Possible causes and solutions for the AI API responses taking a long time to load, including checking the request flow and response handling.

**Decision:** Accepted and tested.

**Why:** The AI evaluation feature was sometimes slow so I used Claude to investigate the issue and understand possible improvements to the API integration and loading behavior. I then tested the changes with the actual application.

## Summary

Overall AI was used as a supporting tool rather than as an autonomous developer. I used it for suggestions, design exploration, repetitive work and debugging while making the final implementation decisions myself.
